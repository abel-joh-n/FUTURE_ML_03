# 📄 Resume Screening & Candidate Ranking System

A Machine Learning and Natural Language Processing (NLP) based Resume Screening System developed as part of **Future Interns - Machine Learning Task 3**.

The application compares resumes against a given Job Description, extracts relevant skills, ranks candidates based on similarity, identifies missing skills, and provides recruiters with an interactive dashboard for efficient candidate shortlisting.

---

## 🚀 Features

- Resume preprocessing using NLP
- Skill extraction from resumes
- Job Description analysis
- TF-IDF Vectorization
- Cosine Similarity based ranking
- Candidate Match Score
- Missing Skill Detection
- Resume Category Search
- Resume Preview
- Download Ranked Candidates as CSV
- Interactive Streamlit Dashboard

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity
- Regular Expressions (Regex)

---

## ⚙ Workflow

1. Load Resume Dataset
2. Clean Resume Text
3. Preprocess Job Description
4. Extract Skills
5. Convert Text using TF-IDF
6. Calculate Cosine Similarity
7. Rank Candidates
8. Identify Missing Skills
9. Display Results using Streamlit
